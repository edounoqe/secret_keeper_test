# 비밀 보관력 테스트 (Secret Keeper Test)

## 1. 프로젝트 소개
비밀 보관력 테스트는 사용자가 상황형 질문에 답하면, 응답 점수를 합산하여 평소 얼마나 신중하게 타인의 비밀을 보관하는지 진단해 주는 Streamlit 기반 웹 애플리케이션입니다.

## 2. 주요 기능
- **첫 화면 학번/이름 표시**: 앱 메인 화면 상단에 과제를 제출하는 학생의 학번과 이름이 명확하게 표시됩니다.
- **로그인 기능**: 사전에 정의된 계정으로만 퀴즈를 풀 수 있도록 세션 관리를 통한 로그인 기능을 구현했습니다.
- **캐싱 기능**: 반복적인 파일 읽기를 방지하여 앱 성능을 높이기 위해 데이터 파일 로드시 Streamlit의 캐싱 기능을 활용했습니다.
- **퀴즈 기능**: CSV 파일에서 상황에 대한 문항과 선택지를 불러오고, 한 번에 폼을 제출하여 응답을 처리합니다.
- **결과 유형 분류**: 사용자의 선택에 부여된 점수를 합산해 3가지 유형(공유 본능형, 상황 판단형, 신뢰 금고형)으로 진단하고 상세한 조언을 제공합니다.

## 3. 실행 방법
로컬 환경의 터미널(또는 명령 프롬프트)에서 아래 명령어를 순서대로 실행합니다.

```bash
# 1. 필요 패키지 설치
pip install -r requirements.txt

# 2. 애플리케이션 실행
streamlit run app.py
```

## 4. 로그인 테스트 계정
해당 앱은 보안 및 퀴즈 응시자 식별을 위해 로그인 기능이 적용되어 있습니다. 앱 실행 후 아래 계정으로 로그인해 주세요.
- **ID**: `student`
- **Password**: `1234`

## 5. 캐싱 기능 설명
Streamlit은 화면 상호작용이 일어날 때마다 파이썬 스크립트를 전체적으로 다시 실행하는 특징이 있습니다. 본 앱은 `data/quiz_data.csv` 파일에서 10개의 문제와 각각의 점수 데이터를 불러올 때, 불필요한 반복 I/O를 막기 위해 데이터 로드 함수(`load_quiz_data()`)에 **`@st.cache_data`** 데코레이터를 적용했습니다. 이를 통해 속도를 향상시키고 자원을 효율적으로 사용합니다.

## 6. 프로젝트 구조
```text
.
├── app.py              # 메인 Streamlit 애플리케이션 코드
├── requirements.txt    # 실행에 필요한 파이썬 패키지 목록 (streamlit, pandas)
├── README.md           # 프로젝트 개요, 실행 방법 및 구조
├── .gitignore          # Git 버전 관리에서 제외할 파일 목록
└── data/
    └── quiz_data.csv   # 퀴즈 질문과 선택지점수가 정의된 데이터 파일
```

## 7. 데모 영상 시연 내용
데모 영상 촬영 시 다음 항목들을 순서대로 보여주시면 됩니다.

1. **기본 화면 출력**: 터미널에서 앱을 실행하고 브라우저가 열렸을 때, 메인 타이틀과 **학번/이름**이 잘 표시되는지 확인.
2. **로그인 실패/성공 통제 로직**:
   - 틀린 비밀번호를 입력하여 실패 알림(`st.error`)이 뜨는 것 보여주기.
   - 올바른 학번/비밀번호(`student` / `1234`)를 입력하여 정상적으로 퀴즈 화면에 진입하는 것 보여주기.
3. **캐싱 안내 문구**: 퀴즈 화면 진입 후 상단에 "퀴즈 데이터는 캐싱을 통해 불러옵니다"라는 문구가 출력되는 부분 짚어주기.
4. **퀴즈 풀이 로직**:
   - 문항 중 일부를 의도적으로 선택하지 않은 채 "제출"을 눌러 **미응답 경고문**(warning)이 폼 제출을 방어하는 모습 시연.
   - 모든 질문에 정상적으로 답변을 선택한 후 제출하기.
5. **결과 화면**: 제출 후 합계 점수가 도출되어 3가지 결과 중 한 가지 유형이 출력되고, 그에 맞는 장점 및 조심할 점 창이 제대로 나오는지 확인.
6. **앱 초기화**: 하단의 "다시 테스트하기" 버튼을 눌러 점수와 세션이 깔끔하게 초기화되고 다시 첫 문항 상태로 돌아가는지 확인.
